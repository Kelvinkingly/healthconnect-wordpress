# HealthConnect — WordPress healthcare portfolio project

**KnowEdge Business Development Services Ltd · Kelvinking Olupitan Omoregie**

HealthConnect is an independently developed healthcare web platform designed around real-world patient access and administrative needs. It is a KnowEdge portfolio project, not a commissioned client engagement. It showcases a patient-centered site structure, searchable directories and maintainable WordPress content. No real patient data, clinical services or appointments are involved.

## Features

- Custom responsive WordPress theme; no commercial page builder required.
- Editable providers, clinics and services in the WordPress dashboard, with specialty and area taxonomies.
- Preconfigured sample entries on first activation, live browser search, and individual profile pages.
- English/Spanish interface examples (selected interface translations; full multilingual content requires further localization).
- Appointment selection workflow that never transmits or stores information; explanatory patient portal concept.
- Keyboard focus styles, skip navigation, labeled forms and live result counts. These are design provisions, not an accessibility certification.

## Installation

1. Create a local WordPress 6.5+ installation with PHP 8.1+ and a supported MySQL/MariaDB version.
2. Copy `theme/healthconnect` into `wp-content/themes/healthconnect` or zip that folder and install using Appearance > Themes > Add New.
3. Activate HealthConnect. Sample directory entries are created on first activation.
4. Open the website homepage; manage directory entries through the Providers, Clinics and Services menus in wp-admin.
5. To deploy publicly use a WordPress-capable PHP/database host. GitHub Pages cannot run PHP or WordPress directly.

## Verification checklist

- Activate on a fresh WordPress environment; verify sample directory entries and profile URLs.
- Edit a provider in wp-admin and confirm the homepage reflects the change.
- Test search, reset, no-match and appointment selection; verify no network submission from the appointment preview form.
- Test mobile layouts, keyboard navigation, screen reader and contrast; conduct formal accessibility testing before any production use.
- Review hosting, backups, rate limits, permissions and appropriate privacy practices before any production extension. Do not collect patient information without an approved production privacy and security design.

## Case study

The design prioritizes common visitor journeys: provider discovery, clinic discovery, service information and an appointment interaction. A structured WordPress model enables administrators to maintain directory entries without editing code. This independent portfolio project illustrates the architecture and user experience envisaged for healthcare organizations; it is not a deployed healthcare service or a claim of regulatory compliance.
